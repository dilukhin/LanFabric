# Ubuntu 20.04: приватный Python для штатного AWG Go

Этап №28 после обновления №32. Исходная основа
`ee793cd99f1dc4db3814eae1826ae5a10f66a6f1`; версия LanFabric 0.0.18 сохранена.
Изменения проверяются в репозитории и одноразовых машинах CI, без рабочих VPS.

## Решение

На чистой Ubuntu 20.04 x86_64 обычный `init --implementation go`, вызванный
через системный Python 3.8 и существующий sudo-контракт, подготавливает готовый
Python 3.12.15 в приватном `/opt/vpn-admin/python-runtime`. Затем та же команда
продолжается на поддержанном интерпретаторе. Основные команды и служба работают
на Python 3.10+, прежнее требование не понижается.

Системный `/usr/bin/python3`, репозитории ОС и её версия не меняются. PPA,
компиляторы, Docker на VPS и ручная сборка не требуются. Контейнер используется
только в CI для испытания настоящей Ubuntu 20.04 со службой systemd.

Готовая поставка получена из официального проекта
[python-build-standalone](https://github.com/astral-sh/python-build-standalone/releases/tag/20261003):

| Свойство | Закреплённое значение |
| --- | --- |
| Файл | `cpython-3.12.15+20261003-x86_64-unknown-linux-gnu-install_only_stripped.tar.gz` |
| Размер | 34 285 590 байт |
| SHA-256 | `731af898886c5f821890dc901eca3c651cca8e51fa7308c159d12a1194aeac91` |
| Целевая архитектура | исходная x86_64, без требования x86_64_v2/v3 |
| Место до приготовления | не меньше 768 MiB свободно; память для Go — не меньше 256 MiB |

По документации upstream эта GNU libc-поставка требует glibc 2.17 или новее;
пригодность для Ubuntu 20.04 подтверждается отдельно реальным испытанием CI.
В архиве сохраняются поставленные upstream сведения о лицензиях. Сторонние
пакеты Python для LanFabric не устанавливаются.

## Проверка и повтор

До скачивания проверяются чистота VPN-цели, собственный приватный модуль root,
платформа и порт. Загрузка ограничена HTTPS, размером и сроком. Архив не
исполняется до совпадения SHA-256. Распаковка ограничивает пути, число файлов
и полный размер; специальные файлы, жёсткие ссылки и выход за корень запрещены.
Внутренние файловые ссылки превращаются в обычные файлы, циклы отклоняются.

До публикации каталога проверяются версия Python, SSL, SQLite и fcntl.
Приватный журнал описывает файлы, каталоги, права и контрольные суммы библиотек.
Каждый вход через поставленный интерпретатор проверяет весь набор, включая
неизвестные файлы. Python запускается с изоляцией окружения и без записи кэша
байт-кода, чтобы набор оставался неизменным. Установленные служебные пути
продолжают соответствовать существующим разрешённым sudo-командам.

Повтор не скачивает и не заменяет пригодный каталог. Повреждённая поставка
отклоняется и не «лечится» удалением. `remove` сохраняет её вместе с данными;
`purge` проверяет точный набор перед остановкой и удаляет только собственную
поставку. Обрыв до публикации может оставить приватный временный каталог;
неизвестные остатки требуют отдельной проверки. Смена этой закреплённой поставки
Python — отдельное обновление, текущий `patch --components` меняет только Go/tools.

## Проверки и оставшиеся границы

Локальные проверки включают выход путей/ссылок за архив, циклы, специальные
файлы, повтор записи, повреждённую загрузку и отказ до исполнения. CI стартует
с системного Python 3.8 внутри Ubuntu 20.04 и проверяет обычный `init`, реальный
systemd, полный профиль, SIGKILL, обновление/возврат/обрыв и remove/reinstall/purge.
Системный Python до и после должен оставаться 3.8.
Контейнер использует сеть своей одноразовой CI-машины: veth не принимается
продуктовой проверкой физического внешнего интерфейса. Проверка не ослабляется;
ядро этой машины остаётся ядром Ubuntu 24.04, пользовательская среда и systemd
внутри контейнера — Ubuntu 20.04. Собственный VPS с ядром своей ОС и холодной
загрузкой ещё требует отдельного испытания.

Фактические результаты относятся к точному коммиту PR и фиксируются после CI.
Холодная загрузка физического/виртуального VPS, перенос действующего v6 и два
реальных клиента этим контейнерным испытанием не закрываются. Ubuntu 22.04/24.04
с подходящим системным Python сохраняют прежний путь без загрузки этой поставки.
